# AI App Compiler Frontend

## Overview

The frontend of AI App Compiler provides an interactive interface for transforming natural language application requirements into structured and executable application specifications.

Built using React and Vite, the frontend serves as the primary interaction layer between the user and the AI compilation pipeline. Users can describe an application idea in plain language, submit it to the backend compiler engine and visualize the generated architecture, validation results and execution status.

This frontend was developed as part of an AI Engineer Internship project focused on building a compiler inspired software generation system.

---

## Project Purpose

The purpose of the frontend is to provide a simple and intuitive interface for interacting with the AI App Compiler backend.

Users can:

Enter application requirements

Submit requests to the compiler pipeline

View generated application summaries

Inspect generated JSON configurations

Review validation results

Check repair actions

Monitor runtime execution outcomes

Switch between multiple output views

## API Communication

The frontend communicates with the FastAPI backend using HTTP requests.

Example workflow:

User submits requirement

Request sent to backend compiler

Compiler processes request

Response returned to frontend

Results displayed in selected view
